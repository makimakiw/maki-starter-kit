# v1.4.0 Changes - Auto-Constitution & Terminal Commands

## Summary
Fixed SpecKit workflow to use terminal commands and automatically create constitution with project context.

## Key Changes

### 1. Auto-Constitution Creation (`lib/setup-speckit.js`)
**What:** After SpecKit initializes, automatically run `specify constitution` with project-specific context

**Details:**
- Includes project name
- References actual design system files (`design-system/pencildraw/`)
- Mentions primary color and CSS variables (`app/globals.css`)
- Sets code standards (Next.js, WCAG AA, mobile-first, etc.)
- Non-fatal if it fails (user can create manually)

**Code:**
```javascript
const constitutionPrompt = `Create principles for ${projectName}:
- Always use components from design-system/pencildraw/ (Button, Input, Modal, EmptyState, Placeholder)
- Always use CSS variables from app/globals.css (primary color is ${primaryColor} mapped to --color-primary)
- Never hard-code colors, spacing, or typography values - always use design tokens
- Follow mobile-first design approach with WCAG AA accessibility standards
- Maintain 44px minimum touch target sizes for interactive elements
- Use Next.js App Router patterns and React Server Components by default
- Keep components simple and composable`;

await execa(specifyPath, ['constitution', constitutionPrompt], { cwd: projectDir });
```

### 2. Terminal Commands Instead of Slash Commands (`bin/cli.js`)

**Before (WRONG):**
```
/speckit.constitution Create principles...
/speckit.specify Build [describe...]
/speckit.plan Use the existing...
/speckit.tasks
/speckit.implement
```

**After (CORRECT):**
```bash
specify specify "Build a user dashboard with profile editing"
specify plan
specify tasks
specify implement
```

### 3. Updated Instructions

**Step 5 Now Shows:**
- ✓ Constitution already created with design system rules
- ✓ Knows about your components and color tokens
- Clear terminal commands instead of chat commands
- File locations for constitution and specs

**Pro Tips Updated:**
- "SpecKit runs in terminal: specify <command>"
- "Constitution is in .specify/memory/constitution.md"
- "Specs are saved in specs/ folder"
