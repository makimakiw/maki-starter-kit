# v2.0.2 - Pencil File Path Fix

## Problem

When running `@CREATE-PENCIL-FILE.md please create the Pencil file` in Cursor chat, the Pencil file wasn't being created. This was because:

1. **Absolute paths used**: The generated CREATE-PENCIL-FILE.md was using absolute Windows paths like:
   ```
   C:\Users\Calle\repo\MakiMalware2\mvp-starter-cli\nice-project\nice-app\design-system\pencil-designsystem-nice-project.pen
   ```

2. **Pencil MCP requires relative paths**: Pencil MCP tools work with paths relative to the Cursor workspace root.

3. **Missing filePath parameters**: The `batch_design` and `set_variables` tool calls were missing explicit filePath parameters.

## Solution

### Changed File Path Format

**Before (v2.0.1):**
```javascript
const pencilFilePath = path.join(projectDir, 'design-system', pencilFileName);
// Results in: C:\...\nice-project\nice-app\design-system\file.pen
```

**After (v2.0.2):**
```javascript
const relativePencilPath = appName 
  ? `${appName}/design-system/${pencilFileName}`
  : `design-system/${pencilFileName}`;
// Results in: nice-app/design-system/pencil-designsystem-nice-project.pen
```

### Updated CREATE-PENCIL-FILE.md Template

Now includes:

1. **Explicit file path display:**
   ```markdown
   **File Path:** `nice-app/design-system/pencil-designsystem-nice-project.pen` (relative to workspace root)
   ```

2. **Workspace root reminder:**
   ```markdown
   **IMPORTANT:** Ensure Cursor workspace is opened at the project root (monorepo folder).
   ```

3. **Explicit filePath in tool calls:**
   ```markdown
   ## Step 2: Add Styled Components
   Use the `batch_design` tool with:
   - filePath: "nice-app/design-system/pencil-designsystem-nice-project.pen"
   - operations: ...
   ```

## How to Use (Correctly)

### 1. Open Cursor at Project Root

**Correct:**
```bash
cd nice-project          # Project root (monorepo)
cursor .                 # Opens workspace at root
```

**Incorrect:**
```bash
cd nice-project/nice-app # App directory
cursor .                 # Wrong! Opens at app level
```

### 2. Run Pencil Creation Command

In Cursor chat:
```
@nice-app/design-system/CREATE-PENCIL-FILE.md please create the Pencil file
```

The `@` symbol references files from the **workspace root**, so:
- Workspace root: `nice-project/`
- File path: `nice-app/design-system/CREATE-PENCIL-FILE.md`
- Reference: `@nice-app/design-system/CREATE-PENCIL-FILE.md`

### 3. Verify Results

After running, you should see:
- ✅ New file created: `nice-app/design-system/pencil-designsystem-nice-project.pen`
- ✅ File contains styled components
- ✅ File contains design tokens/variables
- ✅ File opens in Pencil when clicked

## Technical Details

### Path Resolution

In the monorepo structure:
```
nice-project/                    ← Cursor workspace root
├── nice-app/                    ← App directory
│   └── design-system/
│       ├── CREATE-PENCIL-FILE.md
│       └── pencil-designsystem-nice-project.pen  (created here)
└── package.json
```

- **Cursor workspace root:** `nice-project/`
- **Relative path in MCP:** `nice-app/design-system/file.pen`
- **Absolute path (internal):** `/full/path/to/nice-project/nice-app/design-system/file.pen`

### MCP Tool Parameters

**open_document:**
```json
{
  "filePathOrTemplate": "nice-app/design-system/pencil-designsystem-nice-project.pen"
}
```

**batch_design:**
```json
{
  "filePath": "nice-app/design-system/pencil-designsystem-nice-project.pen",
  "operations": "..."
}
```

**set_variables:**
```json
{
  "filePath": "nice-app/design-system/pencil-designsystem-nice-project.pen",
  "variables": {...}
}
```

## Troubleshooting

### Issue: "File not found" or MCP error

**Solution:** Ensure Cursor is opened at project root:
```bash
cd nice-project  # Not cd nice-project/nice-app
cursor .
```

### Issue: File created in wrong location

**Solution:** Check the CREATE-PENCIL-FILE.md - should show relative path like `app-name/design-system/file.pen`, not absolute path.

### Issue: @reference not working

**Solution:** Make sure to use the full path from workspace root:
```
@nice-app/design-system/CREATE-PENCIL-FILE.md  ✓
@CREATE-PENCIL-FILE.md                          ✗ (not at root)
```

## Migration for Existing Projects

If you created a project with v2.0.0 or v2.0.1, you can regenerate the CREATE-PENCIL-FILE.md:

1. Delete old file:
   ```bash
   rm nice-app/design-system/CREATE-PENCIL-FILE.md
   ```

2. Re-run extraction (from project root):
   ```bash
   cd nice-project
   # Manually re-run extraction or recreate project
   ```

Or manually edit the file to use relative paths instead of absolute paths.
