# v3.0.2 - Simplified Usage (Out of the Box)

## ✅ Problem Solved

You wanted **the easiest way possible** to use MAKI after installation. 

**Before (v3.0.1):**
```bash
git clone https://github.com/makimakiw/maki-starter-kit.git
cd maki-starter-kit
npm install
npm link          # ← Extra step! Easy to forget
maki-init         # ← Command not found if you forget npm link
```

**After (v3.0.2):**


---

## 🚀 What Changed

### Primary Usage: `npm start`

Changed the recommended way to run MAKI from `maki-init` to `npm start`:

**Benefits:**
- ✅ Works immediately after `npm install`
- ✅ No additional setup required
- ✅ No "command not found" errors
- ✅ Simpler for beginners
- ✅ One less thing to remember

### Optional: Global Command

Made `npm link` completely optional for users who want the global `maki-init` command:

```bash
# Optional: For global command
npm link
maki-init  # Now works from anywhere
```

But most users will just use `npm start` - it's simpler!

## 📊 Technical Details

### package.json

No changes needed to `package.json` - it already has:
```json
{
  "bin": {
    "maki-init": "./bin/cli.js"
  },
  "scripts": {
    "start": "node bin/cli.js"
  }
}
```

The `start` script just runs the CLI directly, no installation required!

### How It Works

**`npm start`:**
- Runs `node bin/cli.js` directly
- No global installation needed
- Works from the project directory
- Standard npm convention

**`npm link` (optional):**
- Creates global symlink to `maki-init`
- Allows running from anywhere
- For advanced users who want the convenience
