## New Directory Structure

```
project-folder/               (your project name)
├── .git/                    (git at root)
├── .gitignore              (root ignore file)
├── .specify/               (shared SpecKit)
├── package.json            (workspace config)
└── app-name/               (your app name)
    ├── app/
    │   ├── globals.css     (design tokens)
    │   ├── layout.tsx
    │   └── page.tsx
    ├── design-system/
    │   ├── pencildraw/
    │   │   ├── Button.tsx
    │   │   ├── Input.tsx
    │   │   ├── Modal.tsx
    │   │   ├── EmptyState.tsx
    │   │   └── Placeholder.tsx
    │   ├── CREATE-PENCIL-FILE.md
    │   └── README.md
    ├── public/
    ├── package.json
    ├── tsconfig.json
    ├── postcss.config.mjs
    └── next.config.ts
```

## Root package.json Structure

```json
{
  "name": "project-folder",
  "version": "1.0.0",
  "private": true,
  "workspaces": ["app-name"]
}
```

## Benefits of This Structure

1. **Scalability:** Can add more apps in the future
2. **Clean Separation:** Project concerns vs. app concerns
3. **Shared Resources:** SpecKit specs shared across potential future apps
4. **Professional:** Industry-standard monorepo pattern
5. **npm Workspaces:** Built-in monorepo tooling

## Migration Notes for Users

**For users upgrading from v1.x:**

This is a **breaking change**. New projects will have a different structure:

**Old (v1.x):**
```bash
cd my-app      # Direct to app
npm run dev
```

**New (v2.0.0):**
```bash
cd my-project  # Go to project root
cd app         # Then go to app
npm run dev
```

Users can continue using v1.x for existing projects. This change only affects new projects created with v2.0.0+.
