**Before:**
```bash

git clone https://github.com/makimakiw/maki-starter-kit.git

```

**After:**
```bash
# Step 1: Clone the repository
git clone https://github.com/makimakiw/maki-starter-kit.git

cd maki-starter-kit

# Step 3: Verify you're in the right place (should show: package.json)
ls package.json

# Step 4: Install dependencies
npm install

# Step 5: You're ready! Run MAKI
maki-init
```

**Key improvements:**
- ✅ Numbered steps (1-5) - impossible to miss the order
- ✅ Verification step (`ls package.json`) - confirms correct location
- ✅ Warning message - emphasizes following steps in order
- ✅ Clear explanations for each step
- ✅ Added quick one-liner option for advanced users

### 2. **New Troubleshooting Section in README**

Added comprehensive troubleshooting guide with solutions for:

**Error: "ENOENT: no such file or directory, open 'package.json'"**
- Cause: Not in correct directory
- Solution: `cd maki-starter-kit` and verify with `ls package.json`

**Error: "cd: maki-starter-kit: No such file or directory"**
- Cause: Clone didn't work or wrong parent directory
- Solution: Check with `ls | grep maki` and re-clone if needed

**Error: "Command not found: maki-init"**
- Cause: Need to run from directory or link globally
- Solution: Either `cd maki-starter-kit && maki-init` or `npm link` first

**Installation Checklist:**
- [ ] Cloned the repository
- [ ] Changed into directory
- [ ] package.json exists
- [ ] Installed dependencies
- [ ] Ready to run
