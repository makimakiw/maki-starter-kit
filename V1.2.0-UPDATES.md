# ✅ v1.2.0 Updates - Pushed Successfully!

## What's New

### 🚀 Automatic uv Installation

The CLI now **offers to install uv automatically** when you choose SpecKit!

**Before:**
```
⚠️ SpecKit requires uv which is not installed.
Skipping SpecKit setup.

To use SpecKit in the future:
1. Install uv: curl...
```

**After:**
```
======================================================================
⚡ SPECKIT REQUIRES UV ⚡
======================================================================

SpecKit needs "uv" (Python package manager) which is not installed.

Would you like to install uv automatically?

? Install uv now? (y/N)

[If yes:]
📥 Installing uv...
✓ uv installed successfully
⚠️ Important: Restart your terminal to use uv.
```

### 📋 Clear Pencil Installation Instructions

Added **Step 3** with explicit Pencil installation instructions:

```
📍 Step 3: Install Pencil (if not already installed)

   Pencil is required to create the visual design file.

   In Cursor:
   1. Open Settings (⌘,)
   2. Search for "MCP"
   3. Click "Add MCP Server" or enable Pencil if it's listed

   If Pencil is already installed, skip this step
```

### ✨ Better User Experience

- **Automatic installation** - One command to install uv
- **Clear instructions** - No confusion about what to do
- **Graceful fallback** - If auto-install fails, shows manual steps
- **Terminal restart reminder** - Warns users they need to restart

## What Your Colleague Will See

### New Flow:

1. **Run CLI:** `mvp-init`
2. **Choose SpecKit:** Yes
3. **uv missing?** CLI offers to install it automatically
4. **Accept:** uv installs, CLI tells you to restart terminal
5. **Restart terminal:** Run `mvp-init` again
6. **SpecKit installs:** Automatically, no manual steps
7. **Get instructions:** Including Pencil setup

### Without uv auto-install:

Same as before, but with clearer messaging about what's needed.
